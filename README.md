# YTDL Studio

Repositório público de distribuição dos instaladores do YTDL Studio.

## Downloads

Baixe sempre os arquivos na página de releases:

https://github.com/ytdlguibr/ytdlgui/releases

## Versões disponíveis

- macOS Apple Silicon: para Macs M1, M2, M3 ou mais recentes.
- macOS Intel: para Macs Intel.
- Windows x64: instalador para Windows 64 bits.

## Observações

- Os builds de macOS são assinados ad-hoc para teste interno e ainda não são notarizados pela Apple.
- O instalador do Windows ainda não possui assinatura digital.
- Os links `Source code` exibidos automaticamente pelo GitHub não são instaladores do aplicativo. Use apenas os arquivos DMG/ZIP publicados em cada release.
